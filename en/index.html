    Method and limitations
    
      
      
    • What is counted: for Claude Code, the sum of input, cache-write, cache-read and output tokens recorded for each response (a response written as several lines is counted once); for Codex, per-response usage records (older logs: increments of the cumulative counter). Last 30 days including today; only days with usage count as active days.
      • 
      
    • Measured rank: your position among people who anonymously contributed their numbers here. They are self-selected, so the pool may skew toward heavy users, and edited logs can't be ruled out. The sample size (n) is always shown.
      • 
      
    • Estimated rank: a log-normal fit to the enterprise-developer figures in Anthropic's docs (about $13 per active day on average, 90% under $30, source; median ≈ $5.7/day), converted at $ per 1M tokens (based on the /usage example in the same doc, mostly cache reads). Monthly input is divided by 15 active days. Codex users are outside those figures, so treat it as a rough reference.
      • 
      
    • What is sent: 30-day total tokens, active days, per-tool totals, cache and output ratios, the Codex plan name, and a random ID generated for your browser. This site's database does not store IP addresses; for abuse prevention it keeps only a hash that changes daily, for two days (the hosting provider's normal access logs are separate). Rankings publish only quantiles with the top and bottom 1% trimmed, and submissions are deleted after 180 days.
